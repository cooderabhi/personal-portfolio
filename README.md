# Abhishek Mallick — Personal Portfolio

A premium, responsive personal portfolio website built with HTML5, CSS3, Vanilla JavaScript, and Vite.

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom styling with glassmorphism, animations, and responsive design
- **JavaScript** — Vanilla JS with IntersectionObserver for scroll animations
- **Vite** — Lightning-fast build tool

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- Dark premium design with navy background and indigo accents
- Fully responsive (desktop, tablet, mobile)
- Smooth scroll-reveal animations with IntersectionObserver
- Mobile hamburger navigation
- Active navigation state tracking
- Accessible (keyboard navigation, ARIA attributes, reduced-motion support)
- SEO optimized with meta tags and semantic HTML
- Dynamic copyright year
- Back-to-top functionality

## Deployment

Build the project and deploy the `dist` folder to GitHub Pages, Vercel, or Netlify:

```bash
npm run build
```
